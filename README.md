# AI Impact on Students — Exploratory Data Analysis

**🇮🇹 Italiano | [🇬🇧 English](#english)**

## Panoramica
Analisi esplorativa dei dati sull'uso di strumenti AI e i suoi effetti sul rendimento
accademico, il rischio di burnout e la ritenzione delle competenze tra studenti universitari.

## Dataset
- 50.000 record di studenti (Kaggle - dataset sintetico)
- 42.570 studenti universitari dopo il filtraggio
- 16 feature tra cui GPA, ore di utilizzo AI, rischio di burnout, livelli di ansia

## Domande esplorate
1. L'uso dell'AI migliora davvero il GPA?
2. Il beneficio dipende dalla facoltà?
3. Qual è il costo di un uso intenso dell'AI?
4. La competenza nel prompt engineering fa la differenza?

## Risultati chiave
- L'uso moderato dell'AI supera l'uso intenso in tutte le facoltà
- Gli studenti STEM traggono il beneficio maggiore (Delta GPA: +0.231)
- Gli utenti intensi mostrano un rischio di burnout 6 volte superiore rispetto agli utenti leggeri
- La competenza nel prompt engineering conta più delle ore trascorse a usare l'AI

## Strumenti
- Python, Pandas, Seaborn, Matplotlib, Jupyter Notebook

# AI Impact on Students — Exploratory Data Analysis

**[🇮🇹 Italiano](#ai-impact-on-students--exploratory-data-analysis) | 🇬🇧 English**

## Overview
Exploratory data analysis of AI tool usage and its effects on academic 
performance, burnout risk, and skill retention among undergraduate students.

## Dataset
- 50,000 student records (Kaggle - synthetic dataset)
- 42,570 undergraduate students after filtering
- 16 features including GPA, AI usage hours, burnout risk, anxiety levels

## Questions Explored
1. Does AI usage actually improve GPA?
2. Does the benefit depend on the faculty?
3. What is the cost of heavy AI usage?
4. Does prompt engineering skill make a difference?

## Key Findings
- Moderate AI use outperforms heavy use across all faculties
- STEM students benefit the most (GPA Delta: +0.231)
- Heavy users show 6x more burnout risk than light users
- Prompt engineering skill matters more than hours spent using AI

## Tools
- Python, Pandas, Seaborn, Matplotlib, Jupyter Notebook
